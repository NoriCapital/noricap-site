# noricap.com (marketing site)

The public website for Nori, the AI CFO for owner-led businesses, made by Nori Capital LLC (d/b/a Nori Cap). The app is `NoriCapital/noricap-app` (app.noricap.com); the newsletter is Unboring on Beehiiv.

Philip and Pratibha both work on this repo, each with their own Claude sessions. Read this file first and follow it.

## Pushing to main publishes the site

- Netlify deploys every push to `main` to noricap.com within a minute or two. There is no staging site.
- Before pushing, open the changed pages locally (`python3 -m http.server 8088` in this folder) at desktop and phone width (about 390px). No sideways scrolling, no console errors.
- Pull before you start (`git pull --rebase`). Two people work here; agree who has the repo that day for big changes, or use a branch.
- Each deploy uses Netlify build credits on the $9 Personal plan, so batch small edits into one push.

## How the site is built

- Static HTML, no build step (`netlify.toml` publishes `.`). Fonts from Google Fonts; Google Analytics tag `G-0TMEK057R3` on every page.
- `index.html`: the homepage, with its CSS and JavaScript inline. The FAQ appears twice, in the visible HTML and in the JSON-LD `faq-ld` script near the top; change both together.
- `calculators/`, `compare/` (one side-by-side page) and `for-accountants.html` are generated by a Python script that isn't in the repo. Edit those HTML files directly, keeping the shared header, footer and styles consistent.
- `guides/`, `privacy.html`, `terms.html`, `thanks.html`, `404.html`.
- Screenshots are `img-*.webp`, taken from the app's sample company (Harlow & Pine), never from a real customer.
- Forms (funding, partners, questions, template) are Netlify Forms, found by `data-netlify="true"` and their `name`. A new form needs a new unique name; renaming one starts a new submissions list.
- Unboring sign-ups go through `netlify/functions/subscribe.mjs` (needs `BEEHIIV_API_KEY` in Netlify). Source `template-optin` gets the template welcome email; everything else gets the main welcome.
- `_redirects` holds short URLs and old addresses; `sitemap.xml` lists every public page. Update both when you add, rename or remove a page.
